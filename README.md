# Relógio Web em Tempo Real / Real-Time Web Clock

[PT-BR] Uma aplicação web simples e responsiva de um relógio digital em tempo real desenvolvida para fins de estudo sobre manipulação do DOM, funções temporizadoras (`setInterval`) e estilização com CSS.

[EN-US] A simple, responsive real-time digital clock web application developed for practice with DOM manipulation, timer functions (`setInterval`), and CSS styling.

---

## 🇧🇷 Português

### Contexto do Projeto
Este projeto foi desenvolvido como um exercício prático para fixação de conceitos fundamentais no ecossistema Front-end:
- **Manipulação do DOM:** Seleção e alteração do conteúdo de elementos HTML em tempo real.
- **Trabalho com Datas em JS:** Utilização do objeto nativo `Date` para extrair horas, minutos e segundos do sistema.
- **Temporizadores:** Aplicação da função `setInterval` para criar um ciclo de atualização contínuo a cada segundo (1000ms).
- **CSS3:** Centralização absoluta, layouts em Flexbox, sombras (`box-shadow`) e fundo gradiente.

## English

### Project Overview

This project was developed as a practical exercise to reinforce fundamental Front-End web development concepts:
- **DOM Manipulation:** Selecting and dynamically updating HTML elements in real time.
- **Handling Dates in JS:** Utilizing the native JavaScript `Date` object to extract local system hours, minutes, and seconds.
- **Timers:** Applying `setInterval` to create a continuous execution loop that updates the display every second (1000ms).
- **CSS3 Styling:** Absolute centering, Flexbox layout alignment, drop shadows (`box-shadow`), and gradient background styling.

---

Built strictly using **Vanilla Web Technologies (HTML5, CSS3, and JavaScript)**.
